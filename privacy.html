プライバシーポリシー

「Muse YouTube」（以下「本アプリ」）は、運用者本人が所有するYouTubeチャンネルの運用を補助する個人利用専用のツールです。本ポリシーでは、本アプリがGoogleユーザーデータをどのように取り扱うかを説明します。

取得するデータ

本アプリは、YouTube Data API v3 および YouTube Analytics API を通じて、運用者本人のチャンネルに関する次のデータにアクセスします。

  • チャンネル情報（チャンネル名、登録者数など）
  • 動画の情報（タイトル、概要欄、公開状態など）
  • 分析データ（再生回数、総再生時間、登録者の増減など）

利用目的

取得したデータは、運用者本人のチャンネルへの動画のアップロード、公開予約、動画情報の設定、および投稿実績の分析のためだけに使用します。

保管方法

APIへのアクセスに使う認証情報（アクセストークン等）は、運用者が管理するコンピュータ内の保護された場所に保管し、外部のサーバーへ送信しません。

第三者への提供

取得したデータを第三者へ販売、共有、提供することは一切ありません。

データの削除

運用者は、Googleアカウントのセキュリティ設定から本アプリへのアクセス許可をいつでも取り消すことができます。許可を取り消すと、本アプリはチャンネルのデータにアクセスできなくなります。
